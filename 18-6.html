图 2 · ER 图

智能客服数据模型（实体关系图）

八个实体：用户、会话、消息、意图、知识、工单、坐席、反馈；用竖线与外键符号标注一对多、一对零或一关系。

erDiagram
    USER ||--o{ SESSION : "发起"
    SESSION ||--o{ MESSAGE : "包含"
    SESSION ||--o| TICKET : "转人工"
    AGENT ||--o{ TICKET : "受理"
    INTENT ||--o{ MESSAGE : "识别"
    KNOWLEDGE ||--o{ MESSAGE : "检索命中"
    MESSAGE ||--o{ FEEDBACK : "获得"

    USER {
        int user_id PK "用户主键"
        string nickname "昵称"
        string phone "手机号"
        string channel "来源渠道"
        datetime created_at "注册时间"
    }
    SESSION {
        int session_id PK "会话主键"
        int user_id FK "所属用户"
        string channel "接入渠道"
        string status "会话状态"
        datetime started_at "开始时间"
        datetime ended_at "结束时间"
    }
    MESSAGE {
        int message_id PK "消息主键"
        int session_id FK "所属会话"
        int intent_id FK "命中意图"
        string role "用户 / 机器人 / 坐席"
        string content "消息内容"
        datetime created_at "发送时间"
    }
    INTENT {
        int intent_id PK "意图主键"
        string name "意图名称"
        float confidence "置信度"
        bool is_fallback "是否兜底"
    }
    KNOWLEDGE {
        int knowledge_id PK "知识主键"
        string title "知识标题"
        string category "知识分类"
        string vector_id "向量索引 ID"
        datetime updated_at "更新时间"
    }
    TICKET {
        int ticket_id PK "工单主键"
        int session_id FK "来源会话"
        int agent_id FK "处理坐席"
        string status "处理状态"
        string priority "优先级"
        datetime created_at "创建时间"
    }
    AGENT {
        int agent_id PK "坐席主键"
        string name "坐席姓名"
        string skill_group "技能组"
        string online_status "在线状态"
    }
    FEEDBACK {
        int feedback_id PK "反馈主键"
        int message_id FK "对应消息"
        int rating "满意度评分"
        string comment "用户留言"
        datetime created_at "提交时间"
    }

流程图读法

圆角矩形是处理步骤，菱形是判断分支，箭头上的「是 / 否」表示条件走向；紫色为大模型与检索相关步骤，绿色为人工兜底与沉淀环节。

ER 图符号

||--o{ 表示一对多，||--o| 表示一对零或一；实体框内依次列出字段名、主键 PK、外键 FK 与中文说明。

如何本地渲染

页面通过 ./cdn/mermaid.min.js 引入图表库，再用 mermaid.run() 解析 .mermaid 中的文本并生成 SVG，无需联网。
