LESSON 17 · JSON

JSON 数据展示

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式，用键值对描述对象、用方括号描述数组。下面用一份真实结构的 JSON 数据，演示它的写法、层次与解析方法。

1JSON 的四条基本规则

键值对

"name": "高浩哲"

键名必须用双引号包裹，键与值之间用冒号分隔，多个键值对用逗号分隔。

对象

{ ... }

一对花括号表示一个对象，里面存放若干无序的键值对，可任意嵌套。

数组

[ ... ]

一对方括号表示一个数组，元素用逗号分隔，元素可以是任意 JSON 值。

值类型

6 种

字符串、数字、布尔值、null、对象、数组；不支持函数、undefined 与注释。
