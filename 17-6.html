包饺子的异步流程

先买原料、再取原料，原料到手后「和面」与「和馅」同时开工，两件事都完成后才开始包饺子，包好就开吃。每一步都用 Promise 包装 setTimeout 模拟耗时，再用 async / await 串起整个流程，用 Promise.all 让两个步骤并行。

状态：待开始 总耗时：—
点击「开始包饺子」，按顺序执行买原料 → 取原料 → 和面与和馅（同时）→ 包饺子 → 吃饺子。

    Promise + async / await 代码setTimeout 模拟耗时 
    // 把 setTimeout 包装成返回 Promise 的延时函数
function ghz_sleep(ghz_ms) {
    return new Promise(function (ghz_resolve) {
        setTimeout(ghz_resolve, ghz_ms);
    });
}

async function ghz_cook() {
    await ghz_sleep(6000);  // 买原料
    await ghz_sleep(2000);  // 取原料

    // 和面、和馅同时进行，等两个都完成
    await Promise.all([
        ghz_sleep(5000),  // 和面
        ghz_sleep(3000)   // 和馅
    ]);

    await ghz_sleep(4000);  // 包饺子
    await ghz_sleep(2000);  // 吃饺子
}
