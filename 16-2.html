创建与访问 基础

最常用的是字面量写法 {}。访问属性有两种：点号 obj.name 写法简洁，方括号 obj["name"] 可以用变量当键名。

var stu = { name: "高浩哲", age: 20, "my school": "某大学" // 键名含空格 }; stu.name; // 点访问 stu["age"]; // 方括号 var k = "my school"; stu[k]; // 键名是变量

增 / 删 / 改 / 判断 常用

赋值就是新增或修改：键存在则改值，不存在则新建。delete 删除属性，in 和 hasOwnProperty 用来判断属性是否存在（前者会查原型链）。

var o = { name: "高浩哲" }; o.age = 20; // 新增 o.age = 21; // 修改 delete o.age; // 删除，返回 true "name" in o; // true o.hasOwnProperty("name"); // true

遍历对象 三个方法

Object.keys 拿键、Object.values 拿值、Object.entries 拿“键值对数组”，配合数组方法就能自由加工。for...in 也能遍历，但会带上原型链上的属性，通常要加 hasOwnProperty 过滤。

var score = { 语文: 92, 数学: 88, 英语: 76 }; Object.keys(score); Object.values(score); Object.entries(score); Object.entries(score).map(function (p) { return p[0] + "=" + p[1]; });

解构赋值 提取属性

解构能一次性把对象里的属性“拆”成变量，常用在函数参数上。可以重命名（name: n）、给默认值（= "未知"），也能拆到嵌套和数组里。

var stu = { name: "高浩哲", age: 20, skills: ["HTML", "JS"] }; var { name, age } = stu; var { name: userName } = stu; // 重命名 var { city = "未填写" } = stu; // 默认值 var { skills: [first] } = stu; // 嵌套

展开与浅拷贝 易错点

{ ...obj } 和 Object.assign 都只做第一层复制：改基本类型的属性互不影响，但嵌套的对象 / 数组仍是同一个引用，改一处两边一起变。要彻底分开得用深拷贝。

var a = { name: "原", tags: ["JS"] }; var b = { ...a }; // 浅拷贝 b.name = "改"; a.name; // 仍是"原" b.tags.push("CSS"); a.tags; // 也被改了！
// 点击运行查看结果
方法与 this 重点

对象里的函数叫方法。普通方法里的 this 指向“调用它的那个对象”。箭头函数没有自己的 this，它只能借用外层的，所以不要在对象方法里随手写成箭头函数。

var counter = { n: 0, inc: function () { this.n++; // this = counter return this.n; } }; counter.inc(); // 1 counter.inc(); // 2
// 点击运行查看结果
构造函数与原型 原理

用 new 调用函数就能批量造对象：函数里的 this 指向新对象。把方法挂在 prototype 上，所有实例共用同一份函数，不浪费内存。

function Person(name, age) { this.name = name; this.age = age; } Person.prototype.say = function () { return this.name + " 今年 " + this.age; }; var p = new Person("高浩哲", 20); p instanceof Person; // true
// 点击运行查看结果
class 类语法 现代写法

class 只是构造函数 + 原型的语法糖，看起来更像其他语言。支持 constructor、get / set 存取器、static 静态方法，以及 extends + super 继承。

class Student { constructor(name) { this.name = name; } get info() { return "学生：" + this.name; } static create(n) { return new Student(n); } } class Monitor extends Student { constructor(name) { super(name); this.duty = "班长"; } }

JSON 与深拷贝 实战

JSON.stringify 把对象变成字符串（可存本地、可发网络），JSON.parse 再转回对象。经典深拷贝 JSON.parse(JSON.stringify(obj)) 会丢掉函数和 undefined，现代直接用 structuredClone 更稳。

var o = { name: "高浩哲", tags: ["JS"] }; var str = JSON.stringify(o); var back = JSON.parse(str); back.tags.push("CSS"); o.tags; // 不受影响，真的分开了 Object.freeze(o); // 冻结，禁止改

原型链是怎么找属性的

自己没有的，就顺着 __proto__ 往上找

访问 p.say() 时，引擎先在 p 自己的属性里找，找不到就去 Person.prototype，再找不到就去 Object.prototype，一直到 null 才算真的没有。这条“层层往上找”的链子就叫原型链。

p（实例对象）

  • name: "高浩哲"
  • age: 20
  • __proto__ ↓
→

Person.prototype

  • say: function ()
  • constructor: Person
  • __proto__ ↓
→

Object.prototype

  • hasOwnProperty()
  • toString()
  • __proto__ ↓
→

null

  • 链条终点
  • 再找不到就是 undefined
