14-2 JavaScript 六种基本数据类型

JavaScript 的六种基本（原始）数据类型：Number（数字）、String（字符串）、Boolean（布尔）、Undefined（未定义）、Null（空值）、Object（对象，含数组与 null）。点击"运行全部"或单张卡片查看 typeof 结果。

NUMBER

Number 数字型

整数、小数、科学计数法，还有特殊值 Infinity 与 NaN。

var ghz_num1 = 42;
var ghz_num2 = 3.14159;
var ghz_num3 = 1.5e10;
// 结果将在此显示
STRING

String 字符串型

由引号包裹的一串字符，支持单引号、双引号和 ES6 反引号。

var ghz_str1 = "高浩哲";
var ghz_str2 = 'JavaScript';
var ghz_str3 = `Hello ${ghz_str1}`;
// 结果将在此显示
BOOLEAN

Boolean 布尔型

只有 true 与 false 两个值，常用于条件判断。

var ghz_isStudent = true;
var ghz_hasLicense = false;
var ghz_cmp = 5 > 3;
// 结果将在此显示
UNDEFINED

Undefined 未定义

变量声明后未赋值，或函数没有 return 语句。typeof 结果就是 "undefined"。

var ghz_unassigned;
var ghz_ret = function(){}();
// 调用无 return 的函数
// 结果将在此显示
NULL

Null 空值

表示"什么都没有"。历史遗留 bug：typeof null 却返回 "object"。

var ghz_empty = null;
var ghz_check = (ghz_empty === null);
// 用 === 判断 null
// 结果将在此显示
OBJECT

Object 对象型

包含普通对象、数组、函数等，是最复杂的类型。typeof [] 也是 "object"。

var ghz_person = { name:"高浩哲", age:20 };
var ghz_arr = [1,2,3];
var ghz_fn = function(){};
// 结果将在此显示
