LESSON 18 · CANVAS

Canvas 粒子文字动画

用 canvas 逐帧绘制粒子，让上千个光点汇聚成「高浩哲」三个字，鼠标靠近时粒子会被推开。

GHZ / PARTICLE FIELD 鼠标移入可推开粒子
粒子数：—

文字如何变成粒子

先把「高浩哲」画到一张隐藏的 canvas 上，按固定间隔读取像素点，非透明的位置就是粒子的目标坐标。

粒子如何运动

每个粒子向自己的目标点加速靠近，速度带阻尼；鼠标在半径范围内产生排斥力，离开后自动回位。

动画如何刷新

用 requestAnimationFrame 逐帧清屏并重绘，配合半透明背景形成拖尾，浏览器切换标签时会自动暂停。

核心代码 
// 1. 采样文字像素，得到粒子目标点
var ghz_off = document.createElement('canvas');
ghz_offCtx.fillText('高浩哲', ghz_x, ghz_y);
var ghz_pixels = ghz_offCtx.getImageData(0, 0, ghz_W, ghz_H).data;

// 2. 每帧让粒子靠近目标点并绘制
function ghz_loop() {
    ghz_ctx.fillStyle = 'rgba(7,11,23,.22)';
    ghz_ctx.fillRect(0, 0, ghz_W, ghz_H);

    ghz_particles.forEach(function (ghz_p) {
        ghz_p.x += (ghz_p.tx - ghz_p.x) * 0.05;   // 靠近目标
        ghz_p.y += (ghz_p.ty - ghz_p.y) * 0.05;
        // ……鼠标排斥后绘制圆点
    });

    requestAnimationFrame(ghz_loop);
}
