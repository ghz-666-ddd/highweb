LESSON 17 · TIMER

JavaScript 的两种定时器

setTimeout 只执行一次，适合做延时提示、延时跳转；setInterval 按固定间隔反复执行，适合做秒表、轮播、实时刷新。两者都用 clearTimeout / clearInterval 取消。

执行一次

setTimeout

在指定的毫秒数之后执行一次回调，执行完自动结束；在触发前可以用 clearTimeout 取消。

演示 · 延时提示
尚未启动，选择下方的延时时间。
// 延时 3 秒后执行一次
var ghz_timer = setTimeout(function () {
    console.log('3 秒到了');
}, 3000);

// 提前取消
clearTimeout(ghz_timer);
反复执行

setInterval

每隔指定的毫秒数就执行一次回调，直到调用 clearInterval 才会停止，必须手动清除。

演示 · 秒表
00:00.00每 30 毫秒刷新一次
已刷新 0 次
// 每 30 毫秒刷新一次界面
var ghz_timer = setInterval(function () {
    ghz_updateClock();
}, 30);

// 停止循环
clearInterval(ghz_timer);

两种定时器对比

对比项 setTimeout setInterval
执行次数 只执行 1 次 无限次，直到被清除
是否需要手动停止 不需要，触发后自动结束 需要，调用 clearInterval
取消方法 clearTimeout(id) clearInterval(id)
返回值 定时器编号（数字） 定时器编号（数字）
典型用途 延时提示、广告自动关闭、延时跳转 秒表、轮播图、倒计时、定时刷新数据
  • 两个方法都属于 window 对象，调用时可以省略 window. 前缀。
  • 延时时间单位是毫秒，1000 毫秒 = 1 秒；实际触发时间会略晚于设定值，不保证绝对精确。
  • 在定时器回调执行前修改页面或重新开始计时，记得先清除旧定时器，避免出现多个计时器同时运行。
  • setInterval 间隔过小会拖慢页面，一般动画用 16 毫秒左右（约 60 帧）即可。
  • 定时器只在当前页面有效，页面关闭或刷新后自动失效。
