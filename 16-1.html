九组常用方法

每组都可以单独运行
push() / pop() 改变原数组

在数组末尾添加（push，可一次加多个）或删除（pop）元素，返回值分别是新长度和被删掉的那个元素。

var a = [1, 2, 3]; a.push(4, 5); // 返回新长度 a.pop(); // 弹出末尾元素
// 点击运行查看结果
unshift() / shift() 改变原数组

在数组开头添加（unshift）或删除（shift）元素。注意：头部操作会让所有元素的下标整体后移或前移，效率比末尾操作低。

var b = [1, 2, 3]; b.unshift(0); // 头部插入 0 b.shift(); // 删除头部元素
// 点击运行查看结果
splice() / slice() 一改一不改

splice(起点, 个数, 新元素…) 直接在原数组上删除/插入/替换；slice(起点, 终点) 只复制一段出来，含头不含尾，原数组不受影响。

var c = [10, 20, 30, 40, 50]; c.splice(1, 2, "A", "B", "C"); c.slice(1, 4); // 复制不下刀
// 点击运行查看结果
concat() / join() 返回新值

concat() 把多个数组或值拼成一个新数组；join(分隔符) 把元素用分隔符连成字符串，是数组转文本最常用的方式。

var x = [1, 2], y = [3, 4]; var z = x.concat(y, 5); z.join("-");
// 点击运行查看结果
indexOf() / includes() / find() 查找

找元素位置用 indexOf（找不到返回 -1），判断存在用 includes（返回布尔），按条件找元素用 find / findIndex。

var f = ["苹果", "香蕉", "橙子"]; f.indexOf("橙子"); f.includes("香蕉"); f.find(function (s) { ... });
// 点击运行查看结果
filter() / map() 返回新数组

filter 按条件筛选，留下返回 true 的元素；map 把每个元素加工后放进新数组。两者都不动原数组，长度不变或变短。

var n = [1, 2, 3, 4, 5, 6]; n.filter(function (v) { return v % 2 === 0; }); n.map(function (v) { return v * 2; });
// 点击运行查看结果
reduce() / forEach() 遍历

forEach 只负责挨个遍历、没有返回值；reduce 能把整个数组“累”成一个结果，比如求和、求最大值、拼字符串。

var n = [1, 2, 3, 4, 5]; n.reduce(function (sum, v) { return sum + v; }, 0); // 初始值 0
// 点击运行查看结果
sort() / reverse() 改变原数组

reverse() 原地反转。sort() 默认把元素当字符串比较，所以 10 会排在 9 前面；数字排序一定要传 (a, b) => a - b 比较函数。

var num = [10, 9, 100, 1]; num.sort(); // 按字符串 num.sort(function (a, b) { return a - b; }); [1, 2, 3].reverse();
// 点击运行查看结果
flat() / fill() / Array.from() 进阶工具

flat(层数) 拍平嵌套数组；fill(值) 用同一个值填满数组；Array.from() 把类数组、字符串、Set 等转成真正的数组。

[1, [2, [3]]].flat(2); new Array(5).fill(0); Array.from("高浩哲"); Array.isArray([]);
// 点击运行查看结果

方法速查表

红色“会”= 改动原数组；绿色“不”= 原数组安全
方法 作用 改变原数组 返回值

pop()删除并返回末尾元素会被删除的元素
unshift(…)在开头添加一个或多个元素会新长度
shift()删除并返回开头元素会被删除的元素
splice(s, n, …)从下标 s 开始删除 n 个并可插入新元素会被删除元素组成的新数组
slice(s, e)截取 [s, e) 区间，含头不含尾不新数组
concat(…)拼接数组或值不新数组
join(sep)用分隔符把元素连成字符串不字符串
reverse()反转元素顺序会反转后的原数组
sort(fn)排序（默认按字符串比较）会排序后的原数组
indexOf(v)查找元素下标不下标，找不到为 -1
includes(v)判断是否包含某元素不true / false
find(fn)返回第一个满足条件的元素不元素或 undefined
findIndex(fn)返回第一个满足条件的元素下标不下标或 -1
filter(fn)筛选出满足条件的元素不新数组
map(fn)逐个加工，映射成新数组不新数组
forEach(fn)逐个遍历执行回调不undefined
reduce(fn, init)累加器，把数组归并成一个值不累计结果
some(fn) / every(fn)是否有满足 / 是否全部满足条件不true / false
flat(n)拍平 n 层嵌套数组不新数组
fill(v)用同一个值填充数组会填充后的原数组
Array.from(x)把类数组 / 字符串 / Set 转为数组不新数组
Array.isArray(x)判断是否为数组不true / false
